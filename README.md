                                    Projekt témája: Iskola klub- és szakkörkezelő rendszer

  Az Iskolai klub- és szakkörkezelő rendszer egy weboldal, amely az iskolákban működő klubok és szakkörök adminisztrációját, szervezését
  és nyilvántartását kezeli. A rendszer célja az, hogy egyszerűbbé és átláthatóbbá tegye a tanulók jelentkezését, valamint megkönnyítse a pedagógusok
  számára a klubok és jelentkezések kezelését.
  A tanulók a rendszerben megtekinthetik az elérhető klubokat és szakköröket, azok leírását, időpontjait, valamint jelentkezési lehetőséget biztosít
  számukra. A pedagógusok létrehozhatnak és módosíthatnak klubokat, kezelhetik a résztvevők listáját, valamint nyomon követhetik a jelentkezéseket.
  A pedagógusok teljes körű jogosultsággal rendelkeznek a felhasználók, klubok és a rendszer működésének kezelésére.
  A projekt célja egy könnyen használható, biztonságos és modern felületet biztosítson, mely támogatja az iskolai közösségi élet szervezését
  és csökkenti a papíralapú adminisztrációt.

  Funkciók:
  Regisztrációs panel
  Felhasználói/Adminisztrációs bejelentkezés
  Adatok kezelése
  Klub/szakkörök megtekintése/bemutatása és jelentkezési lehetőség
  Adminok által felhasználói fiókok kezelése

  Használt technológia
  Frontend - Angulart válassszuk oka, hogy mondtad ebbe tudtok segíteni
  Backend - Java
  Adatbázis - mysql
  Verziókezelés - Github
